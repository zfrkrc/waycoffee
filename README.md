# Way Coffee

Way Coffee markası için repo. Şu an **placeholder** — canlı web sitesi ayrı
repodan (`wayankara`) servis edilir.

## Durum
- Bu depo henüz içerik barındırmıyor.
- Web sitesi: **`wayankara`** (statik nginx) → `waycoffee.com.tr`.
- Kafe yönetim platformu: **`coffee-mng`** (CafeOS Edge).

## Not
Buraya eklenecekse: kaynak kodu/asset'leri ekleyip `README` ve kurulum adımlarını
güncelle. Aksi halde `wayankara` + `coffee-mng` referans alınmalı.
